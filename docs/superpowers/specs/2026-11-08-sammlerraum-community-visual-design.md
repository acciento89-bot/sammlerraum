# Sammlerraum community visual direction

The owner's attached `Sammlerraum_ Deine Welt zum Sammeln.png` supersedes the earlier inferred landing-page and lavender-gallery proposals. The image is a visual reference, not a source of fake user data or authorization to add a transactional marketplace.

## Interface
- Persistent dark navy desktop navigation; compact navigation on mobile.
- Gold cube brand mark, gold active destinations and primary public calls to action.
- Clear sans-serif typography; no legacy green/serif presentation in public or community screens.
- Top search entry, language switching, account and notification access.
- Wide collector hero with original artwork; left-aligned legible white copy.
- Four clear feature links followed by editorial/community content and a right context/category/tip column.
- A matching authenticated workspace with real dashboard metrics, actual collection cards and authorized item photographs.

## Integrity
- Existing visibility, account, media and export policies remain server enforced.
- Public editorial stories are labelled Sammlerraum Redaktion/Editorial. Never invent member counts, likes, comments, users or holdings.
- The template's branded franchise imagery is replaced by original unbranded illustrations.
- Free/Premium offer availability remains determined by the actual configured billing service; UI work does not enable paid providers implicitly.
- Available V1 wishlist/trade-status functionality is exposed; no fictitious checkout or event service.
